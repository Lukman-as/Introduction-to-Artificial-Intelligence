# 🧠 Introduction to Artificial Intelligence — CS188 (UC Berkeley)

> *“Intelligence is not about knowing the answers, it’s about learning how to search for them.”*

Welcome to my implementation of classic **Artificial Intelligence algorithms** developed for  
**CS188: Introduction to Artificial Intelligence** at **UC Berkeley**, taught by  
**Professor Pieter Abbeel** and **Professor Dan Klein**.

This repository brings to life the iconic **Pacman AI projects**, where theory meets practice and abstract algorithms learn to navigate mazes, reason under uncertainty, and make intelligent decisions.

---

## 🎯 About This Repository

This project is a hands-on exploration of foundational AI concepts through carefully designed problem sets. Each algorithm is implemented from scratch and applied to guide Pacman through increasingly complex environments.

The focus is not on Pacman itself — but on the **intelligence behind every move**.

---

## 🧩 Core Topics & Algorithms

### 🔍 Search
- Depth-First Search (DFS)
- Breadth-First Search (BFS)
- Uniform Cost Search (UCS)
- A* Search

### 🎮 Adversarial Search
- Minimax
- Alpha-Beta Pruning
- Expectimax

### 🎲 Decision Making Under Uncertainty
- Markov Decision Processes (MDPs)
- Value Iteration
- Policy Evaluation

### 🤖 Intelligent Agents
- Reflex Agents
- Model-based Agents
- Utility-based Reasoning

---

## 🧪 What You’ll Find Inside

## 🌱 Why CS188?

CS188 is widely regarded as one of the most influential introductory AI courses. It doesn’t just teach *what* algorithms exist — it teaches *how to think like an AI researcher*.

This repository reflects that philosophy:
- Reason before coding
- Understand trade-offs
- Design with intent
